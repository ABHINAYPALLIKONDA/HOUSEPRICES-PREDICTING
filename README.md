House price prediction using Linear Regression with Python and Scikit-learn, including model evaluation and data visualization.
# House Price Prediction using Linear Regression

## Project Overview

This project predicts house prices based on house size using
Linear Regression.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Workflow

1. Load the dataset
2. Select feature and target
3. Split data into training, validation, and testing sets
4. Train Linear Regression model
5. Make predictions
6. Calculate MSE
7. Calculate RMSE
8. Calculate R² Score
9. Visualize actual and predicted prices
10. Check model performance

## Model

Linear Regression

## Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results

Training R²: 0.9824

Validation R²: 0.9828

Testing R²: 0.9809

The training, validation, and testing scores are close,
so there is no obvious sign of overfitting or underfitting
for this dataset.
